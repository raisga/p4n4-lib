**p4n4-lib 0.4.2** knows the ai layer's incident investigator (the `agent` profile): which settings it needs, and which of its secrets can be rotated.

```bash
pip install p4n4-lib==0.4.2    # Python 3.11+
```

## Highlights

- **The `agent` profile's settings:** while `COMPOSE_PROFILES` in the ai layer's `.env` enables `agent`, `validate` requires `AGENT_API_TOKEN` and `AGENT_MODEL` there, the two the service refuses to start without. It ships as an image (`ghcr.io/raisga/p4n4-agent`), so the profile adds no files to check.
- **`AGENT_API_TOKEN` is rotatable:** `secrets.ROTATABLE_KEYS` includes the bearer token of the investigator's status API, so clients that rotate secrets give it a new value.

## Compatibility

- Required by **p4n4 (CLI) 0.4.2**. p4n4-api 0.4.0 and p4n4-emu work with 0.4.0 or later.
- No API removed or changed: a drop-in upgrade from 0.4.1.
