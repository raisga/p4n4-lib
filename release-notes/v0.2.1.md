**p4n4-lib 0.2.1** adds the helpers behind `p4n4 up`'s conflict check, `p4n4 down --all` and safe secret rotation, and accepts the dashboard's device cameras and Feed tab in `.p4n4.json`.

```bash
pip install p4n4-lib==0.2.1    # Python 3.11+
```

## Highlights

- **Container name conflicts:** `compose.name_conflicts(*dirs)` finds the containers from another Compose project that hold the fixed `p4n4-*` names, so callers can explain the clash before Docker fails with "container name is already in use".
- **Every p4n4 project on the host:** `compose.host_projects()` lists them from any directory, with projects that own a shared network ordered last. `compose.down_project()` stops one by name, even when its compose files are gone.
- **Shared network:** `compose.ensure_network(name, subnet)` creates `p4n4-net` with Compose's label, so p4n4-iot adopts it. A `p4n4-net` with no label is recreated while no container uses it.
- **Setup-only secrets:** `secrets.ROTATABLE_KEYS` now holds only the secrets services read at every start. `INFLUXDB_PASSWORD`, `INFLUXDB_TOKEN`, `GRAFANA_PASSWORD` and the n8n keys moved to `secrets.SETUP_KEYS`, because rotating them in `.env` alone locked clients out.
- **`compose.ps`** lists stopped and crashed services, and raises `compose.DockerError` when Docker or Compose fails instead of returning an empty list.
- **Dashboard manifest:** `dashboard.cameras` accepts the phone or tablet's own `back` or `front` camera. `dashboard.feed` configures the new Feed tab (`"feed"` in `tabs`).

## Compatibility

- Required by **p4n4 (CLI) 0.2.1** (`p4n4-lib>=0.2.1`).
- `ROTATABLE_KEYS` is smaller. Code that rotated every key in it now leaves the setup-only secrets alone. Use `SECRET_KEYS` for every secret p4n4 generates.

Full list: [CHANGELOG.md](https://github.com/raisga/p4n4-lib/blob/main/CHANGELOG.md).
