**p4n4-lib 0.3.0** adds `p4n4_lib.system1`, the shared code behind the CLI's System 1 (fast typed decisions with laya), and the manifest settings for p4n4-dashboard's Feed tab, device cameras and Home page.

```bash
pip install p4n4-lib==0.3.0    # Python 3.11+
```

0.2.1 was never published to PyPI, so 0.3.0 also carries its changes, listed under the last three headings below.

## Highlights

- **System 1:** `p4n4_lib.system1` loads question sets and evaluation files with the service's shape checks, computes the metrics and gates (`evaluate`, `size_failures`, `QuestionReport.by_lang` when there are two or more languages, `min_auc` for ranking questions), and fits thresholds, calibration and per-question temperatures. It also builds the decision-log and feedback payloads, `label_lines` for labelling past events (a `ts` without an offset is UTC), and `CLIENT`, the script the CLI runs inside the service container so the API key never leaves it.
- **New rotatable secrets:** `SYSTEM1_API_KEY`, `SYSTEM1_ALERT_TOKEN` and `OPERATOR_INTAKE_TOKEN` join `secrets.ROTATABLE_KEYS`.
- **Dashboard manifest:** `dashboard.home` names the Markdown file shown on the Home tab (default `HOME.md`, kept inside the project). `dashboard.feed` configures the Feed tab (`"feed"` in `tabs`), and `dashboard.cameras` accepts the phone or tablet's own `back` or `front` camera.
- **Container name conflicts:** `compose.name_conflicts(*dirs)` finds the containers from another Compose project that hold the fixed `p4n4-*` names, so callers can explain the clash before Docker fails with "container name is already in use".
- **Every p4n4 project on the host:** `compose.host_projects()` lists them from any directory, with projects that own a shared network ordered last. `compose.down_project()` stops one by name, even when its compose files are gone. `compose.ensure_network(name, subnet)` creates `p4n4-net` with Compose's label, so p4n4-iot adopts it.
- **Setup-only secrets:** `secrets.ROTATABLE_KEYS` holds only secrets services read at every start. `INFLUXDB_PASSWORD`, `INFLUXDB_TOKEN`, `GRAFANA_PASSWORD` and the n8n keys moved to `secrets.SETUP_KEYS`, because rotating them in `.env` alone locked clients out. `compose.ps` lists stopped and crashed services and raises `compose.DockerError` instead of returning an empty list.

## Compatibility

- Required by **p4n4 (CLI) 0.3.0** and **p4n4-api 0.2.0** (`p4n4-lib>=0.3.0`).
- Also makes **p4n4 (CLI) 0.2.1** installable, which needs `p4n4-lib>=0.2.1`.

## Upgrading from 0.2.0

- `ROTATABLE_KEYS` is smaller. Code that rotated every key in it now leaves the setup-only secrets alone. Use `SECRET_KEYS` for every secret p4n4 generates.

Full list: [CHANGELOG.md](https://github.com/raisga/p4n4-lib/blob/main/CHANGELOG.md).
