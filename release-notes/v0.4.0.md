**p4n4-lib 0.4.0** merges the edge layer into the ai layer, where the edge inference runner becomes the `ei-runner` profile, and turns p4n4-edge into p4n4-extras, an optional layer for services outside the core.

```bash
pip install p4n4-lib==0.4.0    # Python 3.11+
```

## Highlights

- **Runner in the ai layer:** the ai layer copies `runner/`, `edge-impulse/` and `onnx/` into new projects. `Layer.profile_files` and `Layer.profile_env_keys` make `validate_project` require the runner's files and `.env` keys only while `COMPOSE_PROFILES` lists `ei-runner`. `layout.runner_layer()` names the layer that runs the runner (`ai`, or a legacy `edge`), for clients that show its health.
- **Extras layer:** `extras` (p4n4-extras) holds optional services outside the core. `Layer.optional` keeps it out of `layers.DEFAULT_LAYERS`, so `--layer all` doesn't scaffold it. `sources.yaml` has `extras_repo_url` in place of `edge_repo_url`.
- **Migration:** `p4n4_lib.migrate.migrate_edge()` moves a project's edge layer into `ai` (the runner's service, spliced into the ai compose file with its comments kept, plus its models and `.env` values), scaffolding a new ai layer from p4n4-ai when the project has none. When the edge layer runs other services (a template's own edge layer), it renames it to `extras` with its Compose project name, so its volumes stay. What it replaces is kept in `edge.pre-migrate/`.
- **Older projects keep running:** `layers.LEGACY_LAYERS` (`{"edge": "ai"}`) lets `layout.ordered` and `layout.compose_dirs` still find an `edge` layer, right after the layer that replaced it. `layout.legacy()` names the legacy layers a project still has.
- **Project `.gitignore`:** `scaffold.write_gitignore()` writes `scaffold.GITIGNORE` (every layer's `.env`, generated credentials, model files, p4n4-api's data) when the project has none.
- **Compose helpers:** `compose.enabled_services()` lists the services `up` would start, so callers can skip a layer with nothing enabled instead of failing with "no service selected". `env.parse_profiles`, `env.add_profile` and `env.remove_profile` moved from `system1`, which keeps its names.

## Compatibility

- Required by **p4n4 (CLI) 0.4.0**, **p4n4-api 0.3.0** and **p4n4-emu** (`p4n4-lib>=0.4.0`).
- The ai layer it scaffolds comes from p4n4-ai with the `ei-runner` profile. The extras layer comes from p4n4-extras.

## Upgrading from 0.3.0

- `edge` is no longer in `LAYERS`. Code that looked it up there should use `layers.LEGACY_LAYERS` to map it to `ai`, or `layout.runner_layer()` to find the runner.
- `edge_repo_url` is gone from `sources.yaml`. Use `extras_repo_url`.
